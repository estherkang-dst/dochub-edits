# Dstillery data & DS-1: how they fit together

{% hint style="success" %}
## Signals in. Audiences out.

Dstillery combines two datasets. One teaches intent. The other finds it at scale.
{% endhint %}

### The two data layers

{% columns %}
{% column %}
#### 1. Opted-in panel data teaches

About 2 million fully consented users reveal the journeys behind decisions.

Their research, comparison, and consideration train the model. The data never targets an individual directly.
{% endcolumn %}

{% column %}
#### 2. Website visitation data reaches

Website activity spans web and mobile behavior across about 400 million devices.

It comes from bidstream partners and web publishing tools. The model uses it to find devices showing learned intent patterns.
{% endcolumn %}
{% endcolumns %}

**Opted-in panel data teaches. Website visitation data reaches.**

For a travel campaign, panel journeys might show future bookers comparing reviews and revisiting flight options. Website activity then identifies devices with comparable behavior.

### From behavior to activation

{% stepper %}
{% step %}
#### Learn the journey

The model observes sequences, not isolated page visits.
{% endstep %}

{% step %}
#### Recognize similar intent

The model identifies devices showing comparable patterns.
{% endstep %}

{% step %}
#### Deliver the audience

The audience is ready for DSP activation. It refreshes every 24 hours.
{% endstep %}
{% endstepper %}
