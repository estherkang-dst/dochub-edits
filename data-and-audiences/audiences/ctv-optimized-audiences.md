# CTV-optimized audiences

### What it is

CTV-Optimized Audiences help you reach the right viewers on connected TV, not just the most viewers. Dstillery uses web browsing and search behavior to understand your customers, then finds similar viewers in CTV environments.

These audiences work with your DSP's device graph. They are built to perform in cookieless environments where traditional targeting falls short.

### Why it's different

{% columns %}
{% column %}
#### Before

Most CTV solutions push web audiences to the big screen. They do not account for how CTV viewing behavior works, resulting in broad reach with poor performance.
{% endcolumn %}

{% column %}
#### After

Dstillery's multimodal AI translates web browsing and search intent into targeting that reaches the right CTV viewers, when your DSP supports porting ID-free signal to CTV inventory.
{% endcolumn %}
{% endcolumns %}

### How it works

{% stepper %}
{% step %}
#### Map cross-channel signals

Dstillery's multimodal AI maps web behavior and search intent across 400M+ devices, then applies that intent to CTV inventory.
{% endstep %}

{% step %}
#### Build the model

A CTV-optimized predictive model is built and delivered to your DSP within 24 hours.
{% endstep %}

{% step %}
#### Reach qualified viewers

The model works seamlessly with your DSP's device graph for qualified reach. It refreshes every 24 hours, which is critical when viewer behavior shifts rapidly.
{% endstep %}

{% step %}
#### Activate

Activate it as user segments, curated deals, or contextual targeting.
{% endstep %}
{% endstepper %}
