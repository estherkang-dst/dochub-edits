# Analyze predictive lift scores

Sometimes you don't want to guess which audience will work. DS-1 can run predictive lift analysis and surface the audiences it expects to perform well against, or in relation to, any topic, brand, or URL you give it. Instead of building an audience and hoping, you start from the ones the model already thinks are likely to move the needle.

### Start with the signal

Use the analysis input to focus your research on the audience opportunities that matter.
