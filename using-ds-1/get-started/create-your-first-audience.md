# Build your first audience

{% hint style="info" %}
**Before you begin:** Confirm that you can access DS-1. If needed, see [First-time access & sign-in](getting-started.md).
{% endhint %}

### From campaign goal to activation

Use DS-1 to turn a campaign goal into an activated audience. Start with the signal you have, then let the agent guide the build.

{% stepper %}
{% step %}
### Confirm your workspace

Use the sidebar selector to confirm your active workspace. Select the marketer and destination before you build.
{% endstep %}

{% step %}
### Choose your starting point

Start a conversation from the home screen. Describe the campaign in plain language, or choose an agent.

Use **Find prebuilt audiences** when you need a ready-to-activate segment. Use **Build or refine an audience brief** when you have a brief or RFP.

Use a custom build agent when you have domains, search terms, or product signals. See [Agents](../agents/) for every option.
{% endstep %}

{% step %}
### Review and build

Review the suggested audience, then refine its seeds on the canvas. Confirm the marketer, destination, and audience name.

Select **Build audience** when the audience matches your campaign goal. DS-1 builds it in the background.
{% endstep %}

{% step %}
### Activate the right reach

Find the completed audience in **Recent Activity**. Choose **Syndicate**, then select the reach size that fits your campaign.

**Standard** is the recommended choice for most always-on campaigns. Confirm the destination before sending the segment.

See [Programmatic (DSPs / SSPs)](activation/programmatic-dsps-ssps.md) for the full build and activation flow.
{% endstep %}

{% step %}
### Keep campaign work together

Add the conversation or audience to a project for recurring client work. Projects keep related chats and files together.

See [Projects](../projects.md) to organize campaign work.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Segments appear in destination platforms on their processing timelines. The Trade Desk typically takes 24 to 48 hours.
{% endhint %}
