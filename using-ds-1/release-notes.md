# Release notes

### October 19, 2026

This release includes new audience-building workflows, project research, and usability improvements.

### Highlights

#### Create deals in DS-1

Create deals directly in DS-1. Go to **Agents → Inventory Packages**, then enter the Deal ID. Fixed pricing is available.

#### Build compound audiences in Agents

Combine multiple audiences into one compound audience without leaving DS-1. The same audience-combination rules apply. Learn more in [Build and activate to a DSP or SSP](../ds-1-foundations/core-use-cases/build-and-activate-to-a-dsp-or-ssp.md).

#### Sensitive category requests

Flag sensitive-category requests in DS-1. Our team reviews each request and sends an approval or decline notification to your **Inbox**.

After approval, you can build your audience. If your request is declined and you still need it, contact your Dstillery team.

Learn more in [privacy-and-data.md](../resources/privacy-and-data.md "mention").

### New and improved

#### Ask DS-1 for segment sizes

Ask DS-1 for an audience size directly in chat. Newly built audiences may need time to size. DS-1 now tells you when sizing is still in progress.

#### Clickable status labels in Recent Activity

Each audience in **Recent Activity** shows its build and syndication status. Select a status label to view syndication details or start a support ticket.

#### Notifications is now Inbox

**Inbox** replaces **Notifications** in the bottom-left corner. It holds all communication between you and Dstillery, including sensitive-category requests.

#### Brand research in Projects

Projects can now search the web for brand information and surface competitors. DS-1 uses this context in every agent you run in the project. Learn more in [Projects](projects.md).

#### Take a tour

New to DS-1? Select **Take a tour** in the top-right corner for a guided platform walkthrough.

#### Name your audience from the start

Every agent now uses the same layout. Name your audience in the right panel before you build.

#### Suggested prompts in agents

Each agent now shows rotating example prompts when you open it. Use them to get started with a relevant request.

#### Updated purchase intent seeds

Purchase intent product seeds have been updated. Use them to create purchase intent audiences from current product signals. Learn more in [Build a purchase intent audience](agents/build-a-purchase-intent-audience.md).

### Fixes

Resolved an issue where audiences appeared stuck in **Building** after the build finished.
