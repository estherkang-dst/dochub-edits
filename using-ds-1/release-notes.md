# Release notes

### November 2026

November brings Meta activation and deep research in more agents.

### New features

**Social Activation for Meta**

Send Dstillery audiences straight to your Meta ad accounts as custom audiences, then track audience size, match rates, and performance. Available for DS-1 Enterprise customers. To get started, add Dstillery as a partner on your Meta ad account, then open Social Activation from Agents. There’s no Facebook sign-in and nothing to install.

**Deep research in more agents**

Deep research now also works in Build a Search LAL audience, Build a domain seeded audience, and Find prebuilt audiences. Turn it on from the + button in the chat. It checks every suggestion against Dstillery's catalog before recommending it.

### Improvements

**How this works guide from the start**

The How this works guide now walks you through an agent's screen before you type anything, adapting to the step you're on.

**Terms of Service notice**

The page you see before signing in now links to the DS-1 Terms of Service.

### October 2026

October brought new audience-building tools, deep research, richer Project research, campaign planning, and usability improvements.

### New features

#### Create ID-free deals in DS-1

Create ID-free deals directly in DS-1. Go to **Agents → Inventory Packages**, then enter the Deal ID. Deals currently use fixed pricing.

#### Build compound audiences in Agents

Combine multiple audiences into one compound audience without leaving DS-1.

#### Sensitive category requests

Flag sensitive-category requests in DS-1. Our team reviews each request and sends an approval or decline notification to your **Inbox**.

After approval, you can build your audience. If your request is declined and you still need it, contact your Dstillery team.

Learn more in [privacy-and-data.md](../resources/privacy-and-data.md "mention").

#### Brand research in Projects

Projects can now search the web for brand information and surface competitors. DS-1 uses this context in every agent you run in the project. Learn more in [Projects](projects.md).

#### Build targetable segments from any document

The Planner lets you upload a document in any format. DS-1 analyzes it, builds personas, then turns them into audiences you can target and activate. Every claim links back to the source document.

Find the Planner as the first recommended agent on Home, or under **Planning** in **Agents**.

#### Campaign optimization in Projects

A new **Campaign Optimization** tab in Projects covers campaign setup, audience selection, approval, live performance against your KPIs, and audience swaps. Learn more in [Projects](projects.md).

#### Insights-first audience recommendations

Audience recommendations, including those based on search keywords, now come from scored behavioral data. Recommendations lead with Insights-ranked audiences grouped into themes, followed by relevant audiences from outside data providers.

This can surface strong audiences you might not have considered.

**Deep research for purchase intent** Use deep research to identify purchase-intent seeds through web research and review every step. Open Build a purchase intent audience under Agents → Planning, then turn on deep research from the + button in the chat.

### Improvements

#### Ask DS-1 for segment sizes

Ask DS-1 for an audience size directly in chat. Newly built audiences may need time to size. DS-1 now tells you when sizing is still in progress.

#### Clickable status labels in Recent Activity

Each audience in **Recent Activity** shows its build and syndication status. Select a status label to view syndication details.

#### Notifications is now Inbox

**Inbox** replaces **Notifications** in the bottom-left corner. It holds all communication between you and Dstillery, including sensitive-category requests.

#### Take a tour

New to DS-1? Select **Take a tour** in the top-right corner for a guided platform walkthrough.

#### Name your audience from the start

Every agent now uses the same layout. Name your audience in the right panel before you build.

#### Suggested prompts in agents

Each agent now shows rotating example prompts when you open it. Use them to get started with a relevant request.

#### Updated purchase intent seeds

Purchase intent product seeds have been updated. Use them to create purchase intent audiences from current product signals. Learn more in [Build a purchase intent audience](agents/build-a-purchase-intent-audience.md).

#### Audience Brief is now Audience Portfolio Explorer

**Audience Brief** has been renamed **Audience Portfolio Explorer**. Use it when you have a brief or campaign goals and want recommended products you can edit, reorder, and export.

Use the Planner when you're starting from a document.

#### Chat previews in the sidebar

Chat previews in the sidebar replace the **History** tab. Pin, delete, or add any chat to a project.

#### How this works tour in every agent

Every agent now includes a **How this works** tour that walks you through a populated canvas.

#### Your company name on Home

The Home greeting now shows your company or agency name.

#### Delete marketers

Open the **Marketer** dropdown at the top, then select **Create/Delete a marketer**. Deleting a marketer sets it to inactive. You'll be asked to confirm.

#### Better seed domain suggestions

Custom URL seed domain suggestions are refreshed, so links no longer lead to irrelevant or missing sites.

**Flexible reach sizes**

Audience Portfolio Explorer now shows different reach sizes. Before you send audiences, DS-1 asks if you want to use a reach size other than the standard one.

**A cleaner Home screen**

You now have a simpler Home layout and streamlined chat box. Use the plus button to add files, select agents or projects, and search the web.

**More accurate Insights for unfamiliar sites**

When a domain isn’t in our data, DS-1 now matches it by subject instead of spelling, so audience signals stay on target. This applies automatically.

**Requests resume after you pick a marketer**

If you start without a marketer, DS-1 opens the marketer list and resumes after you choose one. You do not need to retype your request.

### Fixes

Resolved an issue where audiences appeared stuck in **Building** after the build finished.

* Planner results load faster. Dstillery prebuilt audiences now appear first while LiveRamp audiences continue loading.
* Topic refinement in the Insights agent now shows a single, consistent card.

Pasted term lists in Audience Portfolio Explorer now split into separate search terms, and pressing Escape cancels an entry instead of saving it.
