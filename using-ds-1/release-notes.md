# Release notes

### October 2026

Everything new in DS-1 through October 19, 2026.

### Highlights

#### Create ID-free deals in DS-1

Create ID-free deals directly in DS-1. Go to **Agents → Inventory Packages** and create a deal using its Deal ID. Fixed pricing is currently supported.

#### Build compound audiences in Agents

Combine multiple audiences into one compound audience without leaving DS-1. Compound audiences follow the existing combination rules.

#### Sensitive category requests

Flag sensitive-category requests in DS-1. Our team reviews each request and sends an approval or decline notification to your **Inbox**.

After approval, you can build your audience. If your request is declined and you still need it, contact your Dstillery team.

Learn more in [privacy-and-data.md](../resources/privacy-and-data.md "mention").

### New and improved

#### Ask DS-1 for segment sizes

Ask DS-1 for an audience size directly in chat. Newly built audiences may need time to size. DS-1 lets you know when sizing is still in progress.

#### Clickable status labels in Recent Activity

Each audience in **Recent Activity** shows its build and syndication status. Select a label to view syndication details or open a support ticket.

#### Notifications is now Inbox

**Inbox**, in the bottom-left corner, now holds all communication between you and Dstillery. This includes sensitive-category requests.

#### Brand research in Projects

Projects can now search the web for brand information and surface competitors. DS-1 uses this context for every agent you run in the project.

#### Take a tour

New to DS-1? Select **Take a tour** in the top-right corner for a guided platform walkthrough.

#### Name your audience from the start

Every agent now uses the same layout. Name your audience in the right panel before you build.

#### Suggested prompts in agents

Each agent now shows rotating example prompts when you open it. Use them to get started quickly.

#### Refreshed purchase intent seeds

Purchase intent product seeds have been updated. They are current, and every link works.

### Fixes

Audiences no longer appear stuck in **Building** after the build finishes.
